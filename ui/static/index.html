cert-cli

Generate, validate, and inspect CA material locally. PEMs stay on screen until you save them to disk.

Generate certificate chain

Create a root CA, an intermediate, and leaf certificates with custom subject names and validity windows.

Each leaf is signed by the new intermediate. Enter a whole number from 1 to 100.

Relative to the directory where you started cert-cli ui. Writes the certificate, private key, and public key for the root, the intermediate, and every leaf.

Prepended to every saved file name. Example: valid_ writes valid_rootcert.pem.

Validate signature

Check that a certificate was signed by a given root, and inspect OpenSSL-style details.

View certificate

Paste or upload a PEM certificate to decode it into OpenSSL-style details.
